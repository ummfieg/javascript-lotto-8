# javascript-lotto-precourse

### 구현 기능 목록

✅ 기능

1. 구매자는 로또 구입 금액을 입력하여 로또를 발행할 수 있다.
2. 구입 금액만큼 1-45 범위 중 중복 없는 6개의 로또번호를 발행할 수 있다.
3. 구매자는 6개의 당첨번호와 1개의 보너스 번호를 중복 없이 입력할 수 있다.
4. 당첨 내역을 확인할 수 있다.
5. 수익률을 확인할 수 있다.
6. 잘못된 입력 발생 시 해당 시점부터 재 입력할 수 있다.

❗️ 예외

1. 구입 금액은 1,000원 단위로 나누어떨어져야 한다.
2. 구입금액 입력시 숫자 형태여야하고, 공백이 포함될 수 없다.
3. 당첨번호는 1-45 숫자 범위 이내여야한다.
4. 당첨번호는 6개, 보너스번호는 1개여야 한다.
5. 당첨번호와 보너스번호는 중복되지 않아야 한다.
6. 당첨번호 및 보너스번호는 숫자 형태여야 하며, 공백이 포함될 수 없다.
7. 당첨번호는 쉼표(,)로 구분되어야 한다.

🚦검증

1. 발행된 로또 개수가 구매 금액에 맞게 출력되어야 한다.
2. 당첨번호 입력시 쉼표 구분자만 사용해야 한다.
3. 각 로또 번호는 오름차순으로 정렬되어야 한다.
4. 당첨번호 일치 개수별 등수 내역이 정확히 출력되어야 한다.
5. 5개 + 보너스볼 일치 시 보너스볼 내역이 포함되어야 한다.
6. 수익률이 올바르게 계산되어야 하며, 소수점 둘째 자리에서 반올림되어야 한다.
